# Fly-Sim

Две (и больше) независимые мухи-дрозофилы с полными нервными системами из коннектомов, яблоко,
которое гниёт, размножение — и поведение, которое ничем не скриптуется: всё, что муха «решает»,
возникает из симуляции её нейронов.

- **Самка:** мозг FlyWire v783 — 138 639 нейронов, 15 млн связей.
- **Самец:** Male CNS v1.0 (Janelia) — 164 587 нейронов, мозг + брюшная нервная цепочка.
- **Нейроны:** LIF-модель Shiu et al. 2024, совпадает с эталоном Brian2 спайк-в-спайк
  (9054/9054); ~1,7 с счёта на 1 с жизни мозга на Apple M2.

## Запустить и смотреть (живой режим)

```bash
.venv/bin/python -m flysim.live --males 1 --females 1 --apple-days 2
```

Открыть http://localhost:8800 — арена, мухи и мозг каждой мухи (все нейроны на реальных
местах, вспыхивают при спайках), голод, хоботок, песня, P1, память, яйца/личинки/куколки.
Между сессиями (по 60 с, считается нейрон-в-нейрон, ~×0.1 от реального времени) мир
перематывается на сутки: яблоко гниёт, мухи голодают, яйца развиваются, вылупляются новые мухи
со своими мозгами (до 4 одновременно — лимит памяти 8 ГБ).

Параметры: `--session 60 --ff-hours 24 --max-adults 4 --males 2 --females 0` (драки).

## Эксперименты и отчёт

```bash
scripts/run_all.sh
```

```bash
.venv/bin/python scripts/report.py
```

Записи прогонов — `results/*/`, просмотрщик записи: `python -m flysim.viz.export results/<прогон>`.

## Что внутри

| Модуль | Что делает |
|---|---|
| `flysim/brain/lif.py` | Событийный LIF-симулятор (Numba), пластичность KC→MBON под дофамином |
| `flysim/brain/factory.py` | Мозг самки/самца с биологическими поправками (A03, A06–A09) |
| `flysim/agent/senses.py` | Органы чувств → реальные сенсорные нейроны: обоняние (DoOR), вкус, термо, зрение, слух, интероцепция |
| `flysim/agent/metabolism.py` | Зоб, энергия, голод → чувствительность (нейромодуляция) |
| `flysim/agent/motor.py` | Нисходящие нейроны с известной функцией → движения, хоботок, песня, яйцеклад |
| `flysim/agent/body.py` | Упрощённое тело: ходьба по полу и яблоку, полёт, посадка |
| `flysim/world/` | Гниющее яблоко, запахи, тепловые зоны, взаимодействия, жизненный цикл |
| `flysim/sim/experiments.py` | Пары, драки, T-лабиринт + память, избегание места, поиск еды, конфликт |
| `flysim/live/` | Живой режим |
