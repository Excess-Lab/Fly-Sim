## Fly-Sim 0.2.0 — методология, полная моторная цепочка, мир с деревьями

**RU**

Методология (по независимому научному ревью)
- Организм не знает, что он в эксперименте: собственная адаптация вместо калибровки, `Fly.pass_time`
- Режим механизмов у каждого результата: `connectome_only` / `connectome_plus_approximations` / `experimental_shortcuts`
- `manifest.json`: ID эксперимента, версия модели, обходы и приближения, полнота нервной системы каждой мухи
- Логирование трёх уровней: нейроны → моторная команда → движение тела
- Протоколы экспериментов (гипотеза, группы, контроли), серии с повторами в несколько процессов, 95 % ДИ, Cohen's d, Welch / Манн–Уитни, расчёт мощности и бюджета (`scripts/series.py`)
- Документы: MODEL_SCOPE, SCIENTIFIC_VALIDATION, EXPERIMENT_DESIGN; осторожные формулировки README

Нервные системы и тело
- Полная моторная цепочка (самец): VNC → мотонейроны мышц ног → активация мышц → суставы NeuroMechFly, обратная связь от проприоцепторов; прыжок через мотонейроны тергальной мышцы
- Проверено: коннектомная VNC не генерирует ритм шага — ритм остаётся за генератором NeuroMechFly (A81)
- Самка с полной ЦНС: BANC 888 (181 627 нейронов) — экспериментально, сравнение с FlyWire на одинаковых тестах
- Ноцицепция ног через VNC; схема тела каждой мухи и травмы (ноги, крылья, усики, глаза)
- Найдено: стабильность обонятельного центра FlyWire держится на одной ошибочной метке медиатора (KNOWN_ISSUES #5)

Мир
- Несколько яблок, размер мира в метрах
- Семена → сеянцы → плодоносящие деревья (стратификация, почва, влага); сезоны и холодовая кома мух
- Добавление мух во время симуляции; на сайте — выбор мозга самки, травмы, метка режима

Исправлено: медиаторы сенсорных нейронов, знак фоторецепторов, разметка вкуса, ходьба по яблоку, CO₂ воздуха, правило обучения с порядком событий, двойной счёт времени.

**EN**

Methodology: organism unaware of experiments (intrinsic adaptation), mechanism mode on every
result, provenance manifest with experiment ID and connectome coverage, three-level logging
(neural → command → movement), experiment protocols with replicated multi-process series,
confidence intervals, effect sizes, power and compute budget, MODEL_SCOPE /
SCIENTIFIC_VALIDATION / EXPERIMENT_DESIGN docs. Full motor chain for the male (VNC → leg motor
neurons → muscles → joints, proprioceptive feedback); the connectome VNC does not produce a
stepping rhythm (documented). Experimental female full CNS (BANC). Leg nociception, body schema
and lesions. Several apples, world size in metres, seeds → seedlings → fruiting trees, seasons.
Many scientific fixes.
