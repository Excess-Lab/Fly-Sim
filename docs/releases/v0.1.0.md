## Fly-Sim 0.1.0

**RU** — первая версия: оцифрованные мозги дрозофил управляют реалистичными телами у гниющего яблока.

- Мозги по коннектомам: самка FlyWire v783 (138 639 нейронов), самец Janelia Male CNS v1.0 (164 587, мозг + VNC); LIF-симулятор совпадает с эталоном Brian2 спайк в спайк (9054/9054), ~8× быстрее
- Биологические поправки, убирающие «разгон» точечной модели; калибровка самца по 7220 общим типам
- Органы чувств через реальные сенсорные нейроны: обоняние (DoOR), вкус, зрение, термо, слух, интероцепция
- Тело NeuroMechFly v2 в MuJoCo; аэродинамика полёта, теплообмен, атмосфера контейнера
- Гниющее яблоко: брожение → уксус, плесень (геосмин, патулин)
- Обучение (дофаминовая пластичность KC→MBON), размножение (яйца → личинки → куколки → новые мухи)
- Сайт: условия → запуск → наблюдение мозгов → логи; Docker

**EN** — first release: digitized Drosophila brains drive realistic bodies next to a rotting apple.
Connectome brains (FlyWire v783 female, Janelia Male CNS v1.0 male), spike-exact LIF simulator,
senses through real sensory neurons, NeuroMechFly bodies in MuJoCo, flight aerodynamics, heat
exchange, container atmosphere, fermenting and moulding apple, dopamine-gated learning,
reproduction, web app, logs, Docker.
