## Fly-Sim 0.3.0

**RU**

Сайт и панель бога
- Главная со всеми идущими и сохранёнными наблюдениями; несколько прогонов одновременно, каждый — в своей вкладке
- Новое наблюдение: свободная симуляция или готовый эксперимент (протокол, группа, seed) прямо из браузера
- Во время работы — добавить самца, самку, яблоко; повтор любого момента
- Хроника (панель бога): шкала событий, фильтры, все события, раскрытие и копирование, переход к моменту; для каждого события — какие области мозга преобладали и как шёл сигнал между областями; преобладание областей во времени
- Паспорт каждой мухи: уникальный ID, родители, нервная система, режим механизмов, индивидуальная выносливость, история жизни
- Реалистичная отрисовка яблок: плесень колониями от раны

Наука
- Самка BANC (мозг + VNC) и самец откалиброваны по типам клеток: три нервные системы согласуются на одинаковых тестах (у самца восстановлен путь сахар → MN9: 0 → 64 Гц)
- Боль ног доходит до дофамина наказания через полную ЦНС — «короткий путь» A24 остался только для самки FlyWire и ударов тока
- Стабилизация полёта через VNC: жужжальца → рулевые мотонейроны крыльев → момент рыскания
- Смертность каждой мухи (Гомперц, голод, жара, холод, аноксия, токсин), тела остаются, естественный конец мира
- Ветер (шлейфы, нейроны ветра), дыхание почвы
- Хроника любого прогона на диске; потокобезопасный запуск нескольких симуляций

Прочее: README на английском + русская версия, лицензия MIT, Docker сохраняет результаты.

**EN**

Multi-run web app with a god-panel chronicle (timeline, filters, expandable/copyable events with the
brain state and inter-region signal flow at that moment, region dominance over time), fly passports,
prepared experiments from the browser, live add fly/apple, replay. BANC female and male calibrated
per cell type so the three nervous systems agree on identical tests; pain from the legs reaches
punishment dopamine neurons through the full CNS; haltere → VNC → wing steering flight loop;
individual mortality and natural end of the world; wind and soil respiration; full run history on
disk; MIT license; English README with a Russian version.
