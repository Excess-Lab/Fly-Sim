# Известные проблемы модели

1. **Жар у самки не доходит до дофамина наказания.** В данных самки (FlyWire) только головной мозг;
   болевые сигналы тела идут через брюшную нервную цепочку. Неприятный стимул для самки:
   CO2 (врождённо неприятный, сам по коннектому активирует PPL107) и горечь.
2. **Остаточная самоподдерживающаяся активность у самца** (~1% нейронов, в основном VNC:
   мотонейроны, включая DLMn с нереалистичной частотой). Возможная причина — генераторы ритма VNC
   без нейромодуляции и электрических синапсов. Отслеживается в каждом прогоне.
3. **Разная детекция синапсов** (FlyWire vs Janelia): у самца больше синапсов на связь.
   Пока используется тот же вес на синапс (A02).
4. **Тело упрощённое** (см. A30+): не полная механика ног и крыльев.
